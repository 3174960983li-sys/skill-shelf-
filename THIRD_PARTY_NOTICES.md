# Upstream skills and catalog metadata

Skill Shelf is a catalog and local management tool. It does not own the skills discovered through GitHub.

- `catalog.snapshot.json` contains names, brief descriptions, classification metadata and source links for the public `openai/skills` curated catalog. The source repository and exact commit are recorded per entry.
- Chinese display names, summaries and classification rules in `lib/catalog.mjs` are maintained by this project. They are not endorsements from upstream authors.
- GitHub search results, SKILL.md files and README excerpts belong to their respective authors. Fetching or collecting a source does not grant redistribution or commercial-use rights.
- Upstream skill folders may have their own license files and dependencies. Review those before installing, executing or redistributing a skill. Repository-level license metadata can be absent or differ from an individual folder's license.
- Runtime downloads, local skill contents, credentials, installation records and backups under `data/` and `.agents/skills/` are excluded from this repository.
